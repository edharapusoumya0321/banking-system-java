# Banking System – Java

## Project Description
A console-based Banking System developed using Java. It allows users to create bank accounts and perform basic banking operations.

## Features
- Create Savings and Current Accounts
- Deposit money
- Withdraw money
- Transfer money between accounts
- Check account balance
- View transaction history
- Generate account statements

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Inheritance
- Encapsulation
- ArrayList and HashMap
- Collections Framework

## Concepts Implemented
- Classes and Objects
- Inheritance
- Method Overriding
- Exception Handling
- Data Management

## How to Run
1. Download or clone this repository.
2. Open the project in Eclipse.
3. Run `Main.java`.
4. Follow the console menu.
